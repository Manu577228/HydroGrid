# HydroGrid security and privacy review

The review covered the public prototype, browser-owned exercises, citizen accounts, the test GPS workspace and private operator access. Source inspection, bounded automated checks and dependency metadata support the conclusions below. A production emergency service would require an independent security assessment, authoritative data agreements, incident response ownership and a privacy retention policy.

## Authentication and access

| Boundary | Access and storage |
| --- | --- |
| Public | Serves the application, health and capability flags, the base synthetic graph, sourced Karnataka bulletins and a dated street snapshot. Public demo entry issues a role only within a browser-owned exercise. |
| Browser-owned exercise | The browser stores a UUID and a separately generated 256-bit proof. The server compares a SHA-256 digest before it issues a two-hour JWT with workspace and role claims. A leaked workspace UUID alone cannot reopen that exercise. Seeded demo roles can act within their own exercise. |
| Citizen account | Registration creates a citizen account with normalized email and a BCrypt cost-12 password hash. Access JWTs live in memory and expire in up to 10 minutes. The 14-day refresh credential uses a 256-bit random value with its digest in PostgreSQL. A refresh rotates the digest without extending the original session. The HttpOnly cookie uses SameSite Strict, `/api/account` scope and Secure on HTTPS. Logout revokes the current session and clears its cookie. A profile call joins the claimed account to its active session on every request. |
| Private field test | The configured access code enables one gated board, shared with other holders of that code. A FIELD JWT lasts eight hours and carries a derived code version so rotation revokes previous sessions. Positions have an owning device and can be removed by that device. A sharing action requires browser geolocation permission and an explicit choice to transmit. |
| Private city operations | Each enrolled operator has one separately configured scope and an access code digest. The server checks the current enrollment and credential version on authenticated requests. Four-hour OPS tokens gate observations, handoff records and IUDX traffic viewing. The traffic viewer has its own read scope. |

Spring Security verifies the token signature and issuer and maps role claims to authorities. Method and storage checks enforce exercise ownership and scoped object access. The public handshake at `/ws` accepts only an owned exercise bearer at STOMP CONNECT and a topic matching its workspace. The outbound interceptor stops delivery after lease expiration. HTTP endpoints handle writes. [REST policy](../backend/src/main/java/com/hydrogrid/config/SecurityConfiguration.java) · [STOMP policy](../backend/src/main/java/com/hydrogrid/config/WebSocketConfiguration.java)

Account mutations require the exact same origin, JSON and HTTPS outside loopback. If `Sec-Fetch-Site` is provided, it must also say same-origin. These checks protect the cookie-backed routes while the other protected APIs use explicit bearer authentication. Signup and login have ten-minute limits by address and, for login, also by normalized email. Refresh has an address limit. Two concurrent password worker slots bound BCrypt work. These controls live in one application process. [Account controller](../backend/src/main/java/com/hydrogrid/api/AccountController.java) · [Account persistence](../backend/src/main/java/com/hydrogrid/api/AccountStore.java)

## Privacy and retention

- The practice SOS sends selected synthetic coordinates. If permitted, the app uses a transient device fix to suggest the nearest practice point. Optional notes stay in IndexedDB. Inactive exercise records are eligible for deletion after 48 hours and a cleanup job runs every 12 hours. Browser outbox and exercise snapshots remain until browser storage is cleared.
- Private field access can explicitly share coordinates and accuracy with others on the test board. Positions are visible for five minutes and test reports for 24 hours. The 15-minute cleanup task removes older rows. A device can stop its location share.
- The agency board retains current observations and open handoffs. It prunes superseded observation history and closed handoffs after 30 days on its scheduled cleanup. Operators enter source and handoff references without personal information.
- Citizen accounts retain email, display name, time zone and a password hash. The account cleanup job removes expired sessions. Email verification, self-service recovery, account deletion and privileged onboarding require additional production workflows. ## Focused review results

The historical pattern scan inspected 19 reachable commits and 255 unique blobs in the review snapshot. It flagged only the known local test values in `.github/workflows/ci.yml`. Credential-shaped file names, connection URIs containing credentials, common provider token forms and private-key markers yielded zero hits. The pattern scan is bounded by its detection rules and does not cover provider dashboards or private conversations.

| Area | Evidence and outcome |
| --- | --- |
| Cross-workspace objects and privileged registration | The store scopes incident, unit, mission and shelter lookups to the workspace. Existing integration and browser coverage checks that another exercise cannot reuse a workspace UUID, read scoped incidents or subscribe to its STOMP topic. Private field and operations APIs require different token roles. The citizen registration DTO and SQL set the identity type independently from exercise roles. [Integration tests](../backend/src/test/java/com/hydrogrid/HydroGridIntegrationTest.java) · [Citizen account integration](../backend/src/test/java/com/hydrogrid/CitizenAccountIntegrationTest.java) · [Exercise API tests](../e2e/tests/api.spec.mjs) |
| Database and browser injection surfaces | Reviewed queries bind parameter values, including search input, spatial coordinates and IDs. Application SQL concatenation selects fixed internal fragments. React renders data as text, and the app's CSV export escapes formula prefixes. The reviewed endpoints accept typed JSON and bounded text without an upload handler. [Incident store](../backend/src/main/java/com/hydrogrid/store/IncidentStore.java) · [Dashboard queries](../backend/src/main/java/com/hydrogrid/api/DashboardController.java) · [CSV export](../frontend/src/intelligence.ts) |
| Feed handling and logs | The NDMA input uses a fixed HTTPS endpoint, byte cap, timeouts and parser restrictions against external entities. The IUDX connector uses fixed provider URLs, response bounds and server-side credentials. Feed warnings record exception types. Public evidence uses synthetic screens and excludes private board records and credential-bearing traces. [NDMA integration](../backend/src/main/java/com/hydrogrid/api/AlertFeed.java) · [IUDX integration](../backend/src/main/java/com/hydrogrid/api/TrafficFeed.java) |
| Remaining prototype risk | Citizen rate limits are process-local. The public exercise, private test access and operator entry have no application rate limiter. Shared field access trusts every code holder. Operational privacy, stronger identity management, abuse controls and capacity testing remain production work. |

## Dependency audit

Public package-advisory data was queried on 27 November 2026 IST. The Java OSV check covered 80 package coordinates. After the two Maven pins, matches fell from 22 across six packages to 10 across three. The repeat query returned no Jackson or PostgreSQL JDBC matches. Its remaining items have seven critical, one high and two moderate package ratings. Scanner severity describes a dependency. The applicability column records the source and configuration review of HydroGrid.

| Finding | Applicability and resolution |
| --- | --- |
| High Vite development-server advisory | The project previously bound its Vite dev server to all interfaces. The candidate pins the same-major 7.3.8 patch and binds dev and preview to `127.0.0.1` by default. Docker serves prebuilt assets from Java, with nginx in the standalone frontend image. The frontend production build passed. The full lockfile audit moved from 1 high, 4 moderate, 1 low to 0 high, 4 moderate, 1 low. `npm audit --omit=dev` and the Playwright lockfile audit reported zero. [Vite advisory](https://github.com/advisories/GHSA-p9ff-h696-f583) · [Vite configuration](../frontend/vite.config.ts) |
| Moderate and low frontend build-process advisories | npm reported glob/minimatch matches in the Workbox PWA build graph and a Windows esbuild development-server advisory. npm's suggested PWA remediation changes the pinned plugin release and its dependency graph. The runtime image serves prebuilt PWA files, and development defaults to loopback. These matches remain tracked. [Glob](https://github.com/advisories/GHSA-3g3m-2fjr-6pw4) · [Minimatch](https://github.com/advisories/GHSA-g3hv-75wg-m249) · [esbuild](https://github.com/advisories/GHSA-g7r4-m6w7-qqqr) |
